Detailed Description

TimeSceneRatio.

Time scene ratio is used to convert time to pixels, and pixels to time In the scene, the time unit is seconds, the pixel unit is pixel, 1 second = 1 pixel When 100% zoom, 1 pixel = 1 pixel When 50% zoom, 1 pixel = 2 pixels When 200% zoom, 1 pixel = 5 pixels
