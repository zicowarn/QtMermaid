Detailed Description

The FlowChartModel class.

This class represents a flowchart model. It uses a DAG graph to represent the flowchart.

See also
FlowNode, FlowEdge

Add an edge.

Parameters
sourceSubgraphThe source subgraph.
sourceIdThe source node ID.
targetSubgraphThe target subgraph.
targetIdThe target node ID.
styleThe edge style.
labelThe edge label.
Returns
True if the edge is added successfully, false otherwise.

Cross-sub-graph edges (main image to sub-graph, sub-graph to main image, sub-graph to sub-graph) should be logically stored in the m_edges of the main image, because：

  1. The main graph manages global topology (A, Sub1, Sub2 and their connections).
  2. The subgraph only manages internal nodes and edges (such as B -> C in Sub1).
  3. Cross subgraph edges affect the hierarchy calculation of the main graph (such as Sub1 -> A adjusts the hierarchy of A).
